# GitHub 上刚开源的 AI 炒股平台，支持大 A、美股

在 GitHub 上新发现一个金融 AI 项目：**ValueCell**。这是一个专为金融投资设计的多 Agent 平台。

## 01 项目简介

ValueCell 采用多智能体架构，模拟了一支专业的投资团队。它把巴菲特、芒格等投资大师的理念做成智能体，涵盖了价值、成长、技术分析以及宏观趋势等不同流派。

- **市场覆盖广**：涵盖美股、加密货币、港股、A 股等多个市场。
- **多代理系统**：多个智能体分工处理市场分析、情感分析等任务。

## 02 工作原理

整个架构由指挥家（Orchestrator）主导。用户输入问题后，指挥家协调各个专家 Agents 进行讨论，最终将反馈结果推送给用户。

## 03 复刻 AI 炒币大赛

项目支持 AutoTradeAgent，可以实现自动化交易竞赛。通过生成折线图，可以直观比较不同 AI 模型（如 Qwen, DeepSeek, ChatGPT）的交易策略和盈亏情况。

## 04 如何快速部署

```bash
# 克隆项目
git clone https://github.com/ValueCell-ai/valuecell.git
cd valuecell

# 配置环境
cp .env.example .env
# 编辑 .env 填入 API 密钥

# 运行应用
bash start.sh  # Linux/Mac
.\start.ps1    # Windows
```
