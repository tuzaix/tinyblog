# GitHub 上 5000 人收藏的 Vibe Coding 神级指南

Vibe Coding 说白了就是开发个应用不再像程序员一样，苦哈哈地写每一行代码，而是化身为导演。只需要保持一种感觉，这种感觉可能是对产品逻辑、用户流程、审美和交互的把握，剩下的体力活全交给 Cursor、Windsurf、Trae 等 AI 编程工具。

用 Karpathy 的话说：我几乎不写代码了，我只负责调整氛围（Vibe），代码会自动长出来。

## 01 项目简介

这个叫 **vibe-coding-cn** 的开源项目让国内开发者能光速跟上这波浪潮。它是 Vibe Coding 氛围感编程的中文指南，汇集了目前全球最顶尖的 AI 编程资源。

### 核心目录

这个开源项目对 Vibe Coding 进行了定义，还挺有意思的：
**Vibe Coding = 规划驱动 + 上下文固定 + AI 结对执行**

它让「从想法到可维护代码」变成一条可审计的流水线，而不是一团无法迭代的巨石文件。

### 中文指南亮点

- **方法论**：提供了一套准则，帮助开发者理解如何与 AI 协作。
- **AI 编程资源**：推荐了最顶尖的模型（如 Claude 3.5 Opus）和 IDE 环境（如 Cursor）。
- **学习资源与文档**：包含数百个精选提示词，涵盖需求澄清、系统架构设计、分步执行等。

## 02 完整流程

项目提供了一个完整的流程，帮助你：
1. **基础设置**：配置最佳的 AI 开发环境。
2. **开发基础功能**：通过规划驱动让 AI 生成核心代码。
3. **丰富细节与修复 Bug**：在现有代码基础上进行迭代和优化。

**总结**：Vibe Coding 践行“规划就是一切”的理念。在让 AI 写代码前，必须有清晰的技术选型、实施规划和模块化设计，防止 AI 因为理解偏差导致项目逻辑混乱。
