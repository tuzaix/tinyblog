# 新挖掘了 3 个牛哄哄的 GitHub 项目，有点意思啊

今天分享三个近期非常火爆的开源项目，涵盖了云端 IDE、开源游戏资源以及 AI 呼叫中心。

## 01 把 VS Code 装进浏览器

**code-server** 可以让你在浏览器里面写代码。它把 VS Code 完整地搬进浏览器中运行，目前已有 75K Star。

- **核心功能**：复刻了 VS Code 的代码高亮、智能提示、插件扩展、终端调试等几乎所有原生功能。
- **使用场景**：在一台 Linux 服务器上安装后，你可以从平板、手机或任何有浏览器的设备访问完整的开发环境。

**开源地址**：[https://github.com/coder/code-server](https://github.com/coder/code-server)

## 02 开源游戏宝藏清单

这个项目是一个精心整理的开源游戏集合，不仅是列表，更是游戏开发与逆向工程的宝库。

- **原创游戏**：如竞技性俯视角射击游戏 Hypersomnia。
- **重制版/逆向工程**：包括《超级马里奥64》完整反编译项目、《GTA3》和《GTA：罪恶都市》的逆向工程版本 RE3 等。

**开源地址**：[https://github.com/bobeff/open-source-games](https://github.com/bobeff/open-source-games)

## 03 微软开源 AI 呼叫中心

微软开源的 **call-center-ai** 可以让 AI 接管电话业务。

- **技术栈**：使用 GPT-4.1 和 GPT-4.1-nano 模型。
- **能力**：具备细腻的理解能力，支持实时对话流式传输，在断线后可以恢复对话。它能理解领域特定术语，并自动生成待办事项列表。

**开源地址**：[https://github.com/microsoft/call-center-ai](https://github.com/microsoft/call-center-ai)
